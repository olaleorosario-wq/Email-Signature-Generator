Gmail

Settings → See all settings → Signature → Create new. Paste, then Save Changes at the very bottom of the page.

Outlook

Settings → Mail → Compose and reply. Paste into the signature box, then pick it as the default for new messages and replies.

Apple Mail

Settings → Signatures. Paste, then untick “Always match my default message font” or Mail strips the styling.
